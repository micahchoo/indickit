Each package alone

22 languages

One name, typed in Latin letters, through every package in every language: deromanize writes it in the language's script, segment counts its letters, phonetic checks that the written name still matches what was typed, and romanize writes it back in Latin letters. A red cross marks a step that broke the name: the native spelling, or the Latin one written back, no longer matches what was typed.

Where it fails

  • deromanize cuts some names short. In names mode the first spelling is sometimes only the start of the name, while the full spelling is second or third: Malayalam “murmu” gives മു first, Kashmiri “Rajnath” gives راج, Urdu “Chandrayaan” gives ان. Words mode writes these whole. The language table shows every case.
  • Manipuri in Latin letters. romanize drops syllables of Manipuri written in Bengali script (রামেন becomes “en”).
  • A joiner inside a Hindi word. When a press office types an invisible joiner after a virama (प्राप्‍त), romanize keeps only the end of the word (“the”). 212 Hindi words of the 50 releases do this.
  • Common words in Latin letters. romanize gives some frequent words an English look-alike: एक becomes “ac”, देकर becomes “decker”.
  • Singh, fixed, at a cost. In 0.6.0, Hindi सिंह (no g) did not match “Singh”. 0.8.0 reads Latin “ngh” as anusvara + h: they match now, and “Singh” also matches “Sinha”. Bengali and Assamese write সিং, with no h, and that still misses “Singh” (the language table shows it). In phonetic-search, Hindi “singh” ranks संघ (union) above सिंह.
  • Tamil spells some sounds its own way. Tamil writes Lakshmi as லட்சுமி (ட்சு for க்ஷ), so its sound key differs from “Lakshmi”.
  • Too short a stem. stem gives Tamil செய்தி (news) and செய்து (did) one stem, so a word search for one finds the other.

How this was measured: the 50 releases are a held-out slice of the August 2023 month of pib-parallel, chosen by a hash of the release ID before anyone read them. No indickit rule was chosen on this text. The counts on this page were fixed before the text was read, and read once. The language table's preset names were written ahead of time by deromanize and romanize, since their tables for 22 languages weigh about 60 MB. Everything else runs live in this page.
